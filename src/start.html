01 / OFFICE MAC

给办公室 Mac 装上 mobd。

确认这是一台运行 macOS 13+ 的 Apple Silicon Mac。先安装并登录你选择的 Codex CLI 或 Claude Code。

从下载页复制 mobd 安装命令，在办公室 Mac 的终端中执行。安装使用当前用户，无需 sudo。你也可以下载并查看脚本后再执行。

# 默认安装位置加入 PATH（当前终端）
export PATH="$HOME/.local/bin:$PATH"

mobd --version
mobd init

要在后续终端中使用，将 PATH 配置加入 ~/.zshrc。mobd init 创建 ~/.mobd/config.json，已有配置不会被覆盖。

02 / SET THINGS UP

配置连接，授予系统权限。

编辑 ~/.mobd/config.json，设置监听地址、工作目录和 Agent 路径。下面以 Codex 为例，替换用户名和程序路径：

{
  "listen": "0.0.0.0:8080",
  "workdir": "/Users/you/Projects",
  "codexBin": "/absolute/path/to/codex",
  "runners": ["codex"],
  "defaultRunner": "codex",
  "codexPermissions": "approve"
}

用 command -v codex 查找路径。使用 Claude Code 时改为 claudeBin、runners: ["claude"] 、defaultRunner: "claude" 和 claudePermissions: "approve"，并删除 Codex 专用设置。JSON 中必须使用绝对路径，~ 和 $HOME 不会展开。终端用户通过 JSON 配置即可，无需 .env。

仅在受信任网络中连接

0.0.0.0:8080 允许其他设备连接。请使用内网或 VPN，并通过网络访问控制限制来源；不要设置公网端口转发。当前 mobd API 没有用户认证。

  1. 系统设置 → 隐私与安全性：为实际运行桌面操作的程序授予辅助功能和屏幕录制权限。按 macOS 提示重新启动相关进程。
  2. 系统设置 → 通用 → 共享：启用屏幕共享，允许需要使用的 macOS 用户。
  3. 确认办公室 Mac 保持开机、联网，且桌面可用。
mobd start
mobd status

# 可选：登录 macOS 时自动启动
# 首先停止已有服务，再启用登录启动
mobd stop
mobd start --login

mobd status 显示监听地址及健康检查。修改配置后执行 mobd restart。

03 / YOUR MAC

打开 mob，连接你的搭档。

  1. 在你身边的 Mac 上下载 mob DMG，将 mob.app 拖入 Applications，然后打开。
  2. 进入 Settings → Machines，填写办公室端地址，例如 http://192.168.50.86:8080。这个地址要替换成你的办公室 Mac 的实际内网或 VPN 地址。
  3. 填写办公室 Mac 的 macOS 用户名和密码用于屏幕共享登录，点击 Test connection 查看状态。
  4. 创建对话，先试一个简单任务：“查看当前屏幕，并告诉我你看到了什么。”

实时桌面默认只查看。需要自己操作时，打开全屏并切换 Control。Agent 的模型服务账号和登录配置保留在办公室 Mac。

KEEP YOUR BUDDY CURRENT

更新与卸载。

mob：发布版启动时检查更新，也可以在 Settings → About 中手动检查。确认安装后应用会重新启动；先完成当前任务并保存未发送内容。

mobd：先结束任务，执行 mobd stop，再运行下载页的安装命令。脚本验证下载和 Apple 签名后替换程序，不改动配置与会话数据。完成后执行 mobd start；需要登录启动时使用 mobd start --login。

安装特定历史版本时，下载 mobd/install.sh，执行 sh install.sh --version X.Y.Z。版本链接和校验文件可在更新日志中找到。

卸载 mobd：执行 mobd stop 后删除 ~/.local/bin/mobd。配置在 ~/.mobd，默认会话数据在 ~/Library/Application Support/mob，按需要另行备份或清理。卸载 mob：退出后从 Applications 移至废纸篓。

A FEW GOOD QUESTIONS

常见问题。

为什么连接不上办公室 Mac？

确认 mobd 正在运行、监听地址允许局域网连接，两端处于可互通的内网或 VPN。检查防火墙，然后在 App 中使用 Test connection 查看具体项目。

为什么只能聊天，看不到桌面？

检查办公室 Mac 的屏幕共享和屏幕录制权限，核对 Machines 中的 macOS 用户名和密码。实时画面通过 mobd 的 /vnc 转发，无需单独部署 websockify。

我的内容会发送到哪里？

桌面运行在办公室 Mac，客户端直接连接 mobd。任务内容、截图等是否发送给模型服务取决于你使用的 Agent 和模型配置；请查看对应服务的数据政策。

支持 iPhone、Intel Mac 或 Windows 吗？

当前只提供 macOS Apple Silicon 的 mob 与 mobd。其他平台尚未发布。
