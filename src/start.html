快速开始

在办公室 Mac 上安装 mobd，再用 MOB 客户端配对。大约十分钟。当前 mobd 版本：{{version:mobd}}。

准备工作

  • 一台 Apple Silicon 办公室 Mac，macOS 13 或更新版本，保持开机、联网、用户已登录。
  • 已安装并登录 Codex CLI 或 Claude Code，至少一个。
  • 客户端设备能访问办公室 Mac：同一内网、公司 VPN，或按下文配置远程访问。
  • 客户端：桌面端（macOS 13+）、Android 8.0+ 或 iPhone。

1. 安装 mobd

在办公室 Mac 的“终端”中以普通用户运行，不要加 sudo：

{{install}}

安装器读取最新稳定版本，校验 SHA-256 与 Apple 开发者签名，只把 mobd 安装到 ~/.local/bin。把它加入 PATH 并确认：

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
export PATH="$HOME/.local/bin:$PATH"
mobd --version
指定版本、自定义目录或手动安装 
curl -fsSLO {{base}}/mobd/install.sh
sh install.sh --version X.Y.Z
sh install.sh --install-dir /absolute/path

也可以从下载页获取压缩包，对照 SHA256SUMS 校验后解压，把 mobd 放进 PATH 中的目录。历史版本见更新日志。

2. 配置

mobd init      # 创建 ~/.mobd/config.json，不覆盖已有配置
open -e ~/.mobd/config.json

listen 默认是 0.0.0.0:8080，内网和 VPN 中的设备可以直接连接；只通过 Tailscale 访问时改为 127.0.0.1:8080。codexBin / claudeBin 可以写 PATH 中的命令名；不在 PATH 中时，用 command -v codex 找到绝对路径。

{
  "listen": "0.0.0.0:8080",
  "workdir": "/Users/you/Projects",
  "codexBin": "codex",
  "runners": ["codex"],
  "defaultRunner": "codex",
  "codexPermissions": "approve"
}
{
  "listen": "0.0.0.0:8080",
  "workdir": "/Users/you/Projects",
  "claudeBin": "claude",
  "runners": ["claude"],
  "defaultRunner": "claude",
  "claudePermissions": "approve"
}

"approve" 让 Agent 在执行命令或修改文件前询问你；省略时默认为 "bypass"，不询问。两个 Agent 可以同时启用："runners": ["codex", "claude"]。JSON 中不展开 ~ 和 $HOME，路径请写完整。修改后执行 mobd restart。

只在受信任的网络中开放

所有客户端都要先配对，但 HTTP 不加密。不要把 8080 端口映射到公网；跨网络连接请使用 VPN 或 Tailscale。

3. 系统权限

首次启动时 mobd 会请求缺少的权限，按系统提示允许启动 mobd 的程序（终端或 mobd），也可以在 系统设置 → 隐私与安全性 中手动授予：

  • 辅助功能：用于操作鼠标和键盘。
  • 屏幕与系统录音：用于截图和实时桌面。

实时桌面由 mobd 自己采集和编码，不需要开启“屏幕共享”。在电源设置中避免办公室 Mac 无人值守时睡眠。

4. 启动

mobd start            # 后台运行，直到停止或注销
mobd status           # 监听地址与健康检查
mobd stop && mobd start --login   # 可选：登录 macOS 时自动启动

mobd status 中的检查项应全部通过。日志位于 ~/.mobd/mobd.log，用 mobd logs 跟随查看。

5. 配对客户端

每台设备配对一次，凭据保存在设备的安全存储中，之后自动连接。在办公室 Mac 上用客户端能访问的地址生成邀请：

mobd link --url http://192.168.1.100:8080

终端显示二维码和链接，10 分钟内有效，只能使用一次。HTTP 地址会提示传输未加密，仍可配对。

  1. 在 MOB 中打开 Settings → Machines → Add machine。
  2. 手机扫描二维码，或在任意设备上粘贴完整链接；核对地址后点击 Pair。
  3. 点击 Test connection，然后新建对话试一个简单任务，例如“查看当前屏幕，告诉我你看到了什么”。

实时桌面默认只查看，切换到 Control 后可以亲自操作。用 mobd clients list 查看已配对设备；设备丢失时执行 mobd clients revoke CLIENT_ID，它会立即断开。

远程访问

不在同一内网时，推荐用 Tailscale 为 mobd 提供 HTTPS 入口，不需要公网 IP 或端口映射。

  • Serve（推荐）：办公室 Mac 和客户端都安装 Tailscale，入口只对你的 tailnet 开放，实时桌面走 WebRTC。
  • Funnel：只有办公室 Mac 安装 Tailscale，入口在公网可达（仍需配对），实时桌面改用较慢的 WebSocket。

在办公室 Mac 上安装并登录 Tailscale，把 listen 改为 127.0.0.1:8080 后重启 mobd，再发布入口并用输出的 HTTPS 地址配对：

brew install --formula tailscale
sudo brew services start tailscale
sudo tailscale up
mobd restart
sudo tailscale serve --bg --https=443 http://127.0.0.1:8080
mobd link --url https://office-mac.your-tailnet.ts.net

把示例域名换成 tailscale serve 输出的实际地址，不要追加 :8080。客户端设备安装 Tailscale 并登录同一 tailnet。

使用 Funnel（客户端不装 Tailscale） 
sudo tailscale funnel --bg --https=443 http://127.0.0.1:8080
sudo tailscale funnel status

Funnel 需要 MagicDNS、HTTPS 证书和 Funnel 权限，首次执行时按终端链接启用。这是公网入口：只给可信设备发邀请，保持 mobd 更新。同一端口不能同时使用 Serve 和 Funnel。参见 Funnel 说明。

限制 tailnet 内的访问

在 访问控制中只允许你的设备访问办公室 Mac 的 TCP 443 和 UDP 9527。TCP 443 承载对话和配对，UDP 9527 承载实时桌面的 WebRTC；只放行 443 时画面改用 WebSocket。规则会累加，仅添加新规则不会收紧已有的全放行规则。

连接不通时
  • 先在办公室本机检查：mobd status、mobd logs，以及 curl -i http://127.0.0.1:8080/health（未带凭据返回 401 即正常）。
  • Serve：确认两端都在线且在同一 tailnet，sudo tailscale serve status 显示入口。
  • 入口返回 502：mobd 未运行，或转发目标不是实际的监听端口。
  • 证书错误：使用输出的完整域名，不要改用 IP 或跳过证书验证。
关闭入口 
sudo tailscale serve --bg --https=443 off
sudo tailscale funnel --bg --https=443 off

关闭入口不会撤销已配对的凭据；需要时用 mobd clients revoke。

更新与卸载

更新 mobd：等当前任务结束，执行 mobd stop，重新运行安装命令，再 mobd start（或 mobd start --login）。配置、会话和附件都会保留。

更新客户端：桌面端启动时自动检查更新；Android 下载新 APK 覆盖安装。

卸载 mobd：执行 mobd stop，删除 ~/.local/bin/mobd。配置在 ~/.mobd，会话数据在 ~/Library/Application Support/mob，按需删除。

命令速查

命令作用
mobd init创建 ~/.mobd/config.json，不覆盖已有文件
mobd start作为当前用户的后台服务运行
mobd start --login启动，并在登录 macOS 时自动运行
mobd status监听地址与健康检查
mobd logs跟随日志（Ctrl-C 结束）
mobd restart重新加载配置，保留登录启动设置
mobd stop停止服务，并取消登录启动
mobd serve在前台运行

mobd clients list列出已配对的设备
mobd clients revoke ID撤销一台设备并立即断开

完整配置项见 mobd 配置参考。

常见问题

连接不上办公室 Mac？

确认 mobd 的监听地址、防火墙和两端网络互通，然后在客户端运行 Test connection 查看具体检查项。使用 Tailscale 时见远程访问中的排查步骤。

客户端提示需要重新配对？

这台设备的凭据已被撤销，或办公室重置了认证。重新运行 mobd link --url …，在客户端选择 Pair again 并扫描或粘贴新链接，对话会保留。

能聊天，但看不到桌面？

客户端会显示原因：缺少屏幕录制权限时，授予后重启 mobd；提示 “Update mobd” 时更新办公室端。不需要“屏幕共享”或 macOS 登录密码。

实时桌面流量大吗？

内网和 Tailscale Serve 下使用 WebRTC，码率、分辨率和帧率随网络自动调节，画面不变时几乎不发送数据。可以按办公室选择 Auto / High / Low 画质。

我的内容会发送到哪里？

桌面运行在办公室 Mac，客户端直接连接 mobd。任务内容和截图是否发送给模型服务，取决于你使用的 Agent 和模型配置。

支持 Intel Mac 吗？

目前桌面端和 mobd 只支持 Apple Silicon 的 macOS 13 或更新版本。
