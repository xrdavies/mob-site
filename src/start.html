BEFORE YOU BEGIN

准备工作。

  • 一台 Apple Silicon 办公室 Mac，运行 macOS 13 或更新版本，保持开机、联网、用户已登录。
  • 已安装并登录 Codex CLI 或 Claude Code（至少一个）。
  • 客户端设备能访问办公室 Mac：同一内网、公司 VPN 或 Tailscale。
01 / INSTALL

在办公室 Mac 上安装 mobd。

打开“终端”，以普通用户身份运行（不要加 sudo）：

{{install}}

安装器会读取最新的稳定版本，校验 SHA-256 与 Apple 开发者签名，然后只把 mobd 安装到 ~/.local/bin。无需 Go、Node.js、Python 或源码。

把安装目录加入 PATH，并确认安装成功：

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
export PATH="$HOME/.local/bin:$PATH"
mobd --version
安装指定版本或自定义目录 
curl -fsSLO {{base}}/mobd/install.sh
sh install.sh --version X.Y.Z
sh install.sh --install-dir /absolute/path

可以先阅读下载的脚本再执行。历史版本见更新日志。

不使用安装脚本，手动安装

从下载页获取压缩包，对照 SHA256SUMS 校验后解压：

shasum -a 256 mobd_X.Y.Z_darwin_arm64.tar.gz
tar -xzf mobd_X.Y.Z_darwin_arm64.tar.gz mobd
mkdir -p ~/.local/bin && install -m 755 mobd ~/.local/bin/mobd
codesign --verify --strict --verbose=2 ~/.local/bin/mobd
02 / CONFIGURE

创建并编辑配置。

mobd init      # 创建 ~/.mobd/config.json，已有配置不会被覆盖
open -e ~/.mobd/config.json

mobd init 默认只监听本机（loopback）。要让局域网或 VPN 中的设备直接连接，把 listen 改为 0.0.0.0:8080。用 command -v codex 或 command -v claude 查找 Agent 的绝对路径。

{
  "listen": "0.0.0.0:8080",
  "workdir": "/Users/you/Projects",
  "codexBin": "/absolute/path/to/codex",
  "runners": ["codex"],
  "defaultRunner": "codex",
  "codexPermissions": "approve"
}
{
  "listen": "0.0.0.0:8080",
  "workdir": "/Users/you/Projects",
  "claudeBin": "/absolute/path/to/claude",
  "runners": ["claude"],
  "defaultRunner": "claude",
  "claudePermissions": "approve"
}

"approve" 让 Agent 在执行命令或修改文件前询问你，问题会出现在客户端的审批卡片中。两个 Agent 都安装时，可以同时启用："runners": ["codex", "claude"]。

JSON 中只使用绝对路径

~ 和 $HOME 不会展开。修改配置后执行 mobd restart 生效。

只在受信任的网络中开放

0.0.0.0:8080 允许其他设备连接。请使用内网、VPN 或 Tailscale，并限制访问来源；不要设置公网端口转发。可选的 sharedSecret 只保护写操作，读取、截图和实时桌面仍依赖网络访问控制。

03 / PERMISSIONS

授予系统权限。

  1. 系统设置 → 隐私与安全性 → 辅助功能：允许运行 mobd 的程序（终端或 mobd）。
  2. 系统设置 → 隐私与安全性 → 屏幕与系统录音：同样授权，按提示重新启动相关进程。
  3. 系统设置 → 通用 → 共享 → 屏幕共享：开启，并允许你要登录的 macOS 用户。实时桌面通过 mobd 的 /vnc 转发，无需单独部署 websockify。
  4. 电源设置：避免无人值守时自动睡眠。
04 / START

启动服务。

mobd start     # 后台运行，直到停止或注销
mobd status    # 显示监听地址和健康检查

# 可选：登录 macOS 时自动启动
mobd stop
mobd start --login

mobd status 中的检查项应全部通过。缺少的权限或 Agent 也会在客户端的设置页显示为提醒。日志位于 ~/.mobd/mobd.log，用 mobd logs 跟随查看。

05 / CONNECT

打开 MOB，连接你的搭档。

  1. 安装客户端：macOS（把 mob.app 拖入“应用程序”）、Android（APK）；iPhone 版即将上线。
  2. 进入 Settings → Machines，添加办公室 Mac 的地址，例如 http://192.168.1.100:8080，替换为实际的内网、VPN 或 Tailscale 地址。
  3. 在 Desktop sign-in 中填写办公室 Mac 的 macOS 用户名和密码，用于屏幕共享登录。点击 Test connection。
  4. 新建对话，先试一个简单任务：“查看当前屏幕，并告诉我你看到了什么。”

实时桌面默认只查看。需要自己操作时，打开全屏并切换到 Control。手机上点按即点击、长按为右键、双指滚动、捏合缩放。

AWAY FROM THE OFFICE

从家里连接：Tailscale Serve。

家和办公室不在同一网络时，推荐两端都安装 Tailscale。mobd 保持只监听本机，由 Tailscale 提供仅 tailnet 内可访问的 HTTPS 地址，无需公网 IP 或路由器端口转发。

  1. 两端登录同一 tailnet，并在访问控制中只允许你的设备访问办公室 Mac 的 TCP 443。
  2. 在 ~/.mobd/config.json 中设置 "listen": "127.0.0.1:8080"，执行 mobd restart。
  3. 在办公室 Mac 上启用 Serve：
tailscale serve status
tailscale serve --bg --https=443 http://127.0.0.1:8080
tailscale serve status   # 确认显示 Available within your tailnet

在客户端填写输出中的完整地址，例如 https://office-mac.your-tailnet.ts.net，不要追加 :8080。不要使用 Tailscale Funnel 把 mobd 公开到互联网。

完整步骤与排查见 远程访问指南。

KEEP MOB CURRENT

更新与卸载。

更新 mobd：等当前任务结束，然后：

mobd stop
{{install}}
mobd start            # 或 mobd start --login 恢复登录启动

配置、会话和附件都会保留。

更新客户端：macOS 版启动时自动检查更新，也可在 Settings → About 中手动检查。Android 版下载新 APK 覆盖安装。

卸载 mobd：执行 mobd stop，删除 ~/.local/bin/mobd。配置位于 ~/.mobd，会话数据位于 ~/Library/Application Support/mob，按需备份或删除。

CHEAT SHEET

命令速查。

命令作用
mobd init创建 ~/.mobd/config.json，不会覆盖已有文件
mobd start以当前用户的 LaunchAgent 在后台运行
mobd start --login启动并在登录 macOS 时自动运行
mobd status监听地址与健康检查
mobd logs跟随日志（Ctrl-C 结束）
mobd restart重新加载配置，保留登录启动设置
mobd stop停止服务，并取消登录启动
mobd serve在前台运行，Ctrl-C 停止

完整配置项见 mobd 配置参考。

A FEW GOOD QUESTIONS

常见问题。

为什么连接不上办公室 Mac？

确认 mobd status 正常，listen 允许来自你的网络（loopback 只能本机访问），两端处于可互通的内网、VPN 或 tailnet，并检查防火墙。然后在客户端使用 Test connection 查看具体项目。

为什么只能聊天，看不到桌面？

检查办公室 Mac 的屏幕共享和屏幕录制权限，核对 Machines 中的 macOS 用户名和密码。没有桌面登录信息时，客户端只显示截图快照。

安装器提示 mobd 正在运行？

先结束任务并执行 mobd stop（前台运行的 mobd serve 需手动停止），再重新运行安装命令。

我的内容会发送到哪里？

桌面运行在办公室 Mac，客户端直接连接 mobd。任务内容、截图等是否发送给模型服务取决于你使用的 Agent 和模型配置，请查看对应服务的数据政策。

支持 iPhone、Intel Mac 或 Windows 吗？

iPhone 与 iPad 版即将上线；Android 版已可下载。MOB 桌面端和 mobd 目前只支持 macOS Apple Silicon。
