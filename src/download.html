BEFORE YOU BEGIN

第一次见面，先准备这些。

查看完整安装指南 →
1一台办公室电脑

Apple Silicon、macOS 13+ 的 Mac，或 Ubuntu / Debian 的 Linux 电脑（实体机或虚拟机，需要 systemd），保持开机联网。已安装并登录 Codex 或 Claude Code。

2系统权限

Mac：为 mobd 授予辅助功能与屏幕录制权限，无需开启“屏幕共享”。Linux：无需授权，mobd desktops doctor 会检查所需的软件包。

3可达的网络与配对

同一内网或公司 VPN 可以直接连接；跨网访问请按 Tailscale 配置指南选择私有 Serve 或客户端免 VPN 的 Funnel。两种方式都必须通过 mobd link 配对，不要把 mobd 的 HTTP 端口直接开放到公网。
