TWO SIDES. ONE WORKFLOW.

让工作留在办公室。
让你，保持连接。

mobd 在办公室的 Mac 或 Linux 电脑上运行 Agent 和桌面操作（Linux 上每个对话有自己的虚拟桌面）；MOB 是你身边的客户端，用来发起任务、查看结果和连接桌面。

你身边的设备MOB · macOS / Android / iOS
内网 · VPN · Tailscale
办公室的 Mac / Linuxmobd + Codex / Claude Code

桌面不会被迁移到云端虚拟机。任务内容是否发送给模型服务，取决于你选择的 Agent 和模型配置。
