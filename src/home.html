桌面端与办公室端支持 macOS（Apple Silicon）。Android 已可下载，iPhone 通过 TestFlight 提供。

对话驱动任务

用自然语言交给 Codex 或 Claude Code。回复、命令、文件修改和每一步工具调用都显示在时间线中。

问题与审批

Agent 需要确认时，问题出现在客户端，通知同时送达。你回答之后，任务继续执行。

实时桌面

通过 WebRTC 查看办公室桌面，需要时切换到控制模式，用鼠标、键盘或手势亲自操作。

工作方式

两端，一条连接。

Agent 和桌面留在办公室，你身边的设备只负责发起任务和查看结果。

你的设备

MOB

macOS 桌面端、Android 和 iPhone 客户端。用 mobd link 生成的二维码或链接配对一次，之后自动连接。

mobd link --url …
  1. 安装 mobd在办公室 Mac 上运行一行安装命令，再 mobd init 和 mobd start。
  2. 配对客户端运行 mobd link，在 MOB 中扫码或粘贴链接。
  3. 开始任务新建对话，交给 Agent 一件事，跟随它的进度。

Android 和 iPhone 客户端可以对话、上传图片、回答 Agent 的问题，并查看和控制实时桌面。点按即点击，双指滚动，捏合缩放。
